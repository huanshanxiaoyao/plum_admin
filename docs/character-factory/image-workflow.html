01 / INPUT

描述和参考图，至少给一个

文字说清主体、画面用途和想要的感觉；竞品图只提取可复用的视觉特征，不要求用户先会写专业 Prompt。

内容模式会同时传给 Prompt 生成、Midjourney 生图和后续修图。
02 / PROMPT

人工确认 Prompt 后再生图

ChatGPT 把自然语言和参考图整理为完整 Prompt。运营可直接编辑，也可补一句要求重新生成。

确认后锁定 Prompt v3；后续结果必须记录所用 Prompt 版本与内容模式。
03 / GENERATE

Midjourney 返回一组候选图

使用已确认 Prompt，可选择再垫一张图。返回候选后先选主图，也可重新生成或单张放大。

首轮候选保持同一任务组；选择某张图时记录 image_id，作为修图版本链的起点。
04 / RETOUCH

一句指令一次修改，形成版本链

每轮把当前图片与人工指令提交给 ChatGPT 图片编辑。结果作为新版本，不覆盖原图。

可继续修改、前后对比或回退任意版本；只有人工点击“设为最终图”才结束。

核心数据关系

一个图片任务包含：原始输入、内容模式、Prompt 版本、Midjourney 任务与候选图、选中源图、ChatGPT 修图版本链、最终图。任一步失败只重试当前节点，不丢失已确认结果。
