内容模式同时约束生图与生文字；生成结果先到先展示，草稿完成后可并列修改或测试。

01 创意输入02 并发生成03 投稿草稿04 图文修改05 对话测试06 提交
01 / SOURCE

先定模式，再放入创意

先选择 Limited 或 Limitless，再提供候选图片、文字描述或竞品链接；三类至少有一项。

内容模式为必选，默认 Limited。它会同时写入图片和文字提示词；其余创意输入可以自由组合。
02 / GENERATE

图片与文字，同时生成

按已确认的创意、创作意图和内容模式，同时启动生图与生文字。哪路先好就先编辑，结果持续汇入草稿。

两路提示词继承同一个 Limited / Limitless 模式。某一路失败，只重试该路。
03 / DRAFT

生成结果，就是投稿草稿

图片和各类文字直接落到对应字段。草稿形态、必填项、素材规格对齐真实投稿要求。

生成后进入同一个工作台：编辑草稿、描述修改、测试对话都在这里完成。
04 / REVISE

文字和图片，都能继续改

选择改文字或改图片，再描述目标。文字可直接编辑；图片支持局部修改、重新生成、上传替换和裁剪。

基于当前草稿更新，只改选中的部分；展示结果并支持撤销。
05 / TEST

用对话，验证角色感觉

在独立测试框里扮演用户，与当前草稿对话。测试读取最新版草稿，与修改入口并列。

复用线上对话逻辑；修改后可重新测试。测试消息不直接改写角色设定。
06 / SUBMIT

确认后，提交到服务器

校验必填字段、图片与内容规格，再提交当前草稿。成功后返回作品标识和状态，进入后续管理。

校验失败定位补齐；提交失败保留草稿并可重试，避免重复创建。
