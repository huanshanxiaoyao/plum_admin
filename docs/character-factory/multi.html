01 创意来源02 Agent 拆解03 候选池04 并发生成05 批量处理06 提交
01 / SOURCE

第一步，选择模式和来源

先选择 Limited 或 Limitless，再从三种创意来源中选一种；用户只需给原始素材和创作要求。

内容模式为整批任务的必选约束，默认 Limited；随后填写 URL + 需求、纯文字，或图片 + 文字。
02 / AGENT

不同原料，统一拆成候选

Agent 根据当前来源自动选择一条处理路线，再输出可筛选的候选角色方向。运营先看结果，不直接触发角色生成。

统一输出：批次创意摘要、候选图片、文字描述和来源依据；来源依据指原始输入或抓取证据，图片可以没有。
03 / POOL

候选池先筛，再生成

每个候选必须有文字描述和来源依据；候选图片可以为空，也可以手动补充。

运营可编辑、删除、合并或新增候选；先做相似度去重，避免把同一种人设批量复制。
04 / GENERATE

每个候选独立生成，整批并发

每个候选同时生图和生文字；两路提示词继承本批次的内容模式。完成项立即进入草稿，失败项单独重试。

Limited 禁止成人向图文；Limitless 允许成人向图文。完成后的角色可进入工作台编辑与测试。
05 / REVIEW

批量处理共性，单独修复例外

在列表中筛选问题，批量改标签、评级、归属或重新生图；点击某个角色进入工作台，手动编辑或让 Agent 按描述修改，同时测试对话。

工作台修改只作用于当前角色；返回时保留批次筛选、进度和当前定位。
06 / SUBMIT

校验后，提交这一批草稿

统一检查投稿字段、图片规格、归属与评级。可以只提交通过项，也可以修复完成后整批提交。

失败项保留在批次中；服务端回执逐项对应，避免重复创建。

页面边界

本页负责接收来源、Agent 拆解、候选筛选、批量生成和提交。深入修改与对话测试复用单角色工作台；提交后的运营动作归入“线上角色管理”。
